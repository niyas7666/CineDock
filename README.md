## 🎞️ Using the Application

Once you finish the installation, you can launch CineDock from your desktop shortcut or the Windows Start menu. 

### Adding Your Library
When you open CineDock for the first time, the screen shows your library dashboard. You must tell the application where your videos live.

1. Click the Settings icon in the top right corner.
2. Select the Library tab.
3. Click the Add Folder button.
4. Pick the folder on your hard drive that contains your movie files.
5. Click Save. 

CineDock automatically scans the folder for your videos. It displays posters and movie information once the scan completes.

### Playing Videos
Select any movie from the list to view its details. Click the large Play button to start the movie. CineDock opens a new playback window.

### Changing Audio and Subtitles
CineDock handles complex media files like MKV containers. You can change settings during playback:

1. Hover your mouse over the bottom of the playback window.
2. Click the Audio icon to see a list of available sound tracks. Select your preferred language or audio format.
3. Click the Subtitle icon to toggle captions. You can select internal subtitles or upload your own external subtitle file if needed.

## 🛠️ Troubleshooting

If you encounter issues during installation or playback, please check these items first.

**The Application Does Not Start**
Check that you downloaded the 64-bit version of the installer. If your Windows version is outdated, perform a manual update through your system settings. Restart your computer and try launching the file again.

**Black Screen During Playback**
CineDock relies on the VLC engine to decode video. If the video fails to load, verify your video file is not corrupt. Try opening the same file in a standard player to verify if the file format is valid. If the file works elsewhere, update your graphics card drivers via the device manager.

**Missing Subtitles**
Ensure your subtitle files are in the same folder as your movie. If the subtitle file uses a specific format, ensure it matches the naming convention of your video file exactly.
